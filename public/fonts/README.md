- **Family:** Big Apple NF, Version 1.002, single weight **400 (Regular)**
- **License:** Nick's Fonts / 1001Fonts Free For Commercial Use (`1001fonts-bigapple-eula.txt`)
- **Embedding:** `fsType 0` — installable embedding, web use allowed

## Rules

1. Do **not** convert, subset or otherwise modify the file. The EULA forbids
   modification, so it is served as the original OTF.
2. Never pair `font-display` with `font-bold` — the face has no bold cut and the
   browser would synthesize one.
3. Minimum 28px. Below that the hairlines disappear.
4. Latin only. Arabic, Hindi and Cyrillic headings use `font-sans`.
